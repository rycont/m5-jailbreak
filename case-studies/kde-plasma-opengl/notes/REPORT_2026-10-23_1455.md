## 2. plasmashell 실패 — Hazel 진단과 다른 부분

Hazel은 "relay가 wl_seat를 광고하지 않거나 tablet manager를 seat 없이 광고"라고 봤으나, 실측은 다르다.

- KWin의 wayland-3 global 목록에 `wl_seat v9`, `xdg_wm_base v6`, `zwp_tablet_manager_v2 v1`, `zxdg_output_manager_v1 v3`가 **모두 있음** (`/tmp/wlinfo` 실측, 52개 global).
- 문제는 Qt가 **seat 프록시가 NULL인 상태로** 입력 팩토리를 호출하는 것:
  - `zwp_tablet_manager_v2.get_tablet_seat` → `null value passed for arg 1`
  - `wl_data_device_manager.get_data_device` → 같은 오류
  - `zwp_primary_selection_device_manager_v1.get_device` → 같은 오류
- 이 marshal 오류가 `wl_display`의 `last_error=EINVAL`을 세팅해 이후 모든 요청을 오염시키고, 그 결과 `Loading shell integration failed.`가 났다.

### 적용한 우회 (shim)
`wlshim.c`에서 위 3개 null-seat 팩토리 호출을 서버로 보내지 않고 `wl_proxy_create()`로 로컬 더미 프록시를 반환.
결과: **shell integration 오류가 사라짐** (`qt.qpa.wayland: Loading shell integration failed.` 더 이상 없음).

### 다음 블로커 (원문)
```
[WLFLAGS] opcode=1 sig=no iface=zxdg_output_v1
[WLFLAGS] o[1]=(nil)
error marshalling arguments for get_xdg_output (signature no): null value passed for arg 1
qt.qpa.wayland: Failed to initialize EGL display 3001
Couldn't start kglobalaccel ... (비치명)
Could not load a session backend ... (비치명)
The Wayland connection experienced a fatal error: Invalid argument
```
- `get_xdg_output`도 null `wl_output`으로 호출된다. seat뿐 아니라 **Qt가 registry에서 받은 객체 프록시들이 NULL**인 패턴.
- EGL 3001 = `EGL_NOT_INITIALIZED`. plasmashell은 EGL 초기화 실패 후 연결이 fatal error로 종료.
- 추정: Qt의 Wayland 플러그인이 registry bind 결과를 잃거나, 우리 shim의 `wl_proxy_create` 더미가 ID 공간/프록시 수명을 건드렸을 가능성. **미검증**.

## 3. KWin 출력 루프 — 실제 프레임 없음

`animclient`(wl_shm 480x270, 900프레임)을 wayland-3에 붙여 실측:
```
configured=0
frames=900 elapsed=15.341 client_fps=58.66
```
- 클라이언트는 58.66fps로 900프레임을 보냈지만 **KWin이 xdg configure를 한 번도 보내지 않았다** (`configured=0`). 즉 KWin이 새 클라이언트 요청을 디스패치/매핑하지 못하는 상태.
- relay 쪽 지표: `[OSD] commit` 1회, `[XDG] commit` 2회에서 증가 없음. fb1 8회 샘플(1초 간격) 전부 `4ca50413…`.
- 따라서 58.66fps는 **클라이언트 송신 FPS**이며 패널 FPS가 아니다. 패널은 0fps.
- 추정: KWin의 출력 루프가 부모 relay의 frame callback/commit을 기다리며 멈췄거나, KWin의 xdg-shell 서버가 새 표면을 처리하지 못함. **미검증**.
