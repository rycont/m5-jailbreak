# 05 · 복구

## 원칙

1. **부트로더·fstab·파티션은 건드리지 않는다.** 이 저장소의 모든 변경은 `/opt/usr/a`와 런타임 메모리에서 끝난다.
2. 커널 패치는 **원래 워드를 적어두고** 시작한다.
3. 화면이 죽어도 재부팅이면 벤더 스택으로 돌아온다. 단, eMMC 백업이 있으면 더 안전하다.
4. Sway 종료 시 fd를 닫으면 `minor->master`가 NULL이 된다. 벤더 master 객체를 복원하거나 재부팅한다.

## Sway 내리기

```sh
pkill -TERM sway
```

Sway가 master fd를 닫으면 master가 비워집니다. 벤더 컴포지터가 살아 있으면 다시 잡을 수도 있고, 아니면 재부팅이 확실합니다.

## CRTC가 wedge됐을 때

증상: 화면이 마지막 프레임에 멈춤, `PAGE_FLIP`이 `-EBUSY`, `SETCRTC`가 `-EINVAL`.

원인: 완료되지 않은 page flip이 남아 있음.

복구 (`reset.c`):

1. `SETCRTC(fb=0, count_connectors=0, mode_valid=0)`
2. 원래 vendor fb id로 `SETCRTC` (모드 유지)

원래 fb id는 takeover 전에 `GETCRTC`로 읽어둡니다.

## 커널 패치 원복

1. `0x022BA798`, `0x022BA7A0`, `0x022BA7B0`의 원래 32비트 워드를 되돌린다.
2. `minor->master`(phys `0x27B3E2B4`)에 벤더 객체 `0xE5B4A680`을 쓴다.
3. fd를 닫는다.

패치를 남겨두면 다음 부팅까지 `SET_MASTER`가 무조건 성공하는 상태가 됩니다. 보안/안정성 모두 좋지 않습니다.

## 화면이 완전히 검을 때

1. 전원을 뺐다가 다시 연결 (재부팅)
2. 벤더 E가 뜨고 Tizen UI가 돌아오는지 확인
3. 안 돌아오면 eMMC 이미지로 복원

복원 예시(백업 구조에 맞게 경로 수정):

```sh
for n in $(seq 1 24); do
  dd if=/mnt/usb/m5/p$n.img of=/dev/mmcblk0p$n bs=4M
done
sync
```

## 하지 말 것

- `mkfs`, `parted`, `fdisk`로 파티션 수정
- 부트로더 변수 변경
- 벤더 master 객체를 복원하지 않은 채 fd 닫기
- 주소를 확인하지 않고 `kmsown2` 바이너리 재사용
