# 01 · 스택 지도

M5의 그래픽 경로를 한 장으로 그리면 이렇습니다.

```
              foot / KCalc / (Sway)
                       │
        Wayland: wl_surface + buffer(dmabuf or shm)
                       │
        ┌──────────────┴──────────────┐
        │                             │
   Enlightenment (E)              Sway 1.10 / wlroots 0.18
   tizen_policy, tizen_visibility      │
   wl_shell, no xdg_wm_base            │
        │                             │
        │                        pixman 렌더
        │                             │
        │                    dumb buffer (/dev/dri/card0)
        │                             │
        └────────► TBM + libtpl-egl ◄─┘        (E 쪽)
                       │
                  ndp DRM/KMS (card0)
                  CRTC 20 · LVDS · 1920x1080@60
                       │
                    M5 패널
```

## 계층별 역할

| 계층 | 역할 | M5에서 |
|---|---|---|
| **DRM** | GPU/디스플레이 장치 노드, 버퍼 공유, master 소유권 | `/dev/dri/card0` (ndp, Novatek) |
| **KMS** | 모드 설정, CRTC/connector, page flip | 살아 있음. 단 plane 0개 → legacy만 |
| **TBM** | Tizen의 버퍼 할당기. 벤더 드라이버를 감싼 dmabuf 대여소 | 주 경로. `libtpl-egl`이 EGL 연결 |
| **GBM/minigbm** | 리눅스 쪽 벤더 버퍼 할당기 | **없음** |
| **Mesa** | GLES/EGL 구현 | Mali용 존재하나 GBM 경로 부재 |
| **Wayland** | 클라이언트↔컴포지터 운송 규약 | E는 Tizen 확장, Sway는 표준 |
| **컴포지터** | surface 합성 후 KMS로 최종 프레임 전달 | E / Sway |

## 오해 정리

- **"KMS가 없다"** — 틀렸습니다. CRTC 20이 active이고 1080p60으로 스캔아웃 중입니다.
- **"`/tmp/.muse_server_socket`이 디스플레이 master를 쥔다"** — 틀렸습니다. 그 소켓은 미디어/카메라 쪽 `muse-player` 계열입니다.
- **"E는 KMS를 안 쓴다"** — E도 최종 출력은 KMS로 합니다. 다만 입력/정책은 Tizen 확장을 씁니다.
- **"GBM shim만 만들면 Sway가 된다"** — 절반. 버퍼 할당은 바뀌지만 wlroots는 `SET_MASTER`, 모드 설정, page flip을 직접 호출합니다. 그래서 이 저장소는 GBM 대신 **dumb buffer + pixman + legacy KMS**로 갑니다.

## 부팅 직후의 master

부팅 직후 `/dev/dri/card0`의 DRM master는 벤더 디스플레이 스택이 쥐고 있습니다. 정확히 어느 프로세스인지는 이 저장소에서 확정하지 못했습니다(E와 `drm-service` 계열이 함께 뜨고, PID 네임스페이스가 분리되어 추적이 어렵습니다). 확실한 것은:

- 우리 PID 네임스페이스 밖이라 `kill` 불가
- `SET_MASTER`는 `EINVAL` — "이미 master가 있음"이라는 뜻
- master를 비우면 `open()`만으로 획득 가능

이 사실이 [04 · master 탈취](04-master-탈취.md)의 전제입니다.
